# Limitations and remaining gates

- A completed assistant turn after the transport is the available readback signal. The application cannot prove audible playback at the listener's ear. Natural model paraphrases of an exact confirmation question can require another attempt.
- Spoken phone readback is the assignment's only identification mechanism. A caller who knows another person's number can impersonate them. The shared receptionist dashboard intentionally shows appointment history and masked phone suffixes. Use a fictional clinic, loopback or a trusted demo environment.
- Runtime free-form Gemini speech is not a deterministic rendering of the commit journal. Receipts are commit-backed. Audio can fail after a real commit. Consult the appointment register and original reference before retrying.
- Browser usage was Chromium/Edge on Windows. Firefox, WebKit, separate physical devices, TURN traversal, real speaker echo, prolonged endurance, true screen-reader operation and physical audio-device changes remain unverified.
- The upstream report inventory distinguishes observed local behavior from historical upstream bugs. One final synthetic browser call booked and cancelled with Flash-Lite. A naturally spoken corrected-phone booking, physical microphone recording and human demo video remain outstanding.
- The pairwise suite spans seven factors: validity of the phone, positive readback, positive visit vote, interrupted readback, competing booking, closed session and repeated request. SQLite fault, process death, stale receipt and offline dashboard cases have separate tests. This does not cover every higher-order combination.
- Model-based tests track active slots, reference, owner and event count across booking, cancellation and database reopen. They do not model the entire WebRTC, language-model or audio state machine.
- Secret scanning covers recognizable key formats in reachable Git history, nonignored local files and compiled text assets. This review does not establish absence of every possible credential or log disclosure. Previously shared credentials should be rotated locally.
- Six isolated backend mutations were tested. Frontend mutation coverage, resource counts across prolonged calls, full acoustic interruption evaluation and sensor-level confirmation of playback remain outstanding. The scenario inventory marks unexecuted items explicitly.
- The local CI commands were executed. A hosted GitHub Actions run on this change was not observed. Publication of these release changes and candidate submission are separate steps.
