# Defect register

All database examples use fictional caller numbers in disposable databases. The original live appointment history was untouched.

| ID / priority | Reproduction and observed defect | Root cause and fix | Retest evidence |
| --- | --- | --- | --- |
| QA01 / P0 | Confirm a phone, list two doctors, submit one offered slot before the caller agrees. SQLite created a confirmed row. | Offered slots acted as permission to book. The session now proposes an exact doctor, date and time. Booking and moving require a completed matching question and an adjacent positive reply. A move binds the original visit too. | baseline/regressions.txt, tests/test_release.py, tests/test_conversations.py |
| QA02 / P0 | Echo the phone in a sentence containing “correct”, ask an unrelated question and answer yes. The phone became confirmed. | A keyword anywhere in the assistant turn armed the challenge. Require a terminal readback confirmation question. Cancellation now also requires the full question. | baseline/unrelated-yes.txt, test_unrelated_yes_after_phone_echo |
| QA03 / P1 | Supply two alternative complete numbers or malformed repeated digits. The parser silently chose a valid number. | Reverse matching silently preferred the last candidate. Reject alternatives and invalid repetition; retain explicit corrections and normalize Unicode decimal digits. | baseline/regressions.txt, test_ambiguous_numbers_rejected, test_phone_inputs |
| QA04 / P1 | A non-object tool argument raised AttributeError and unexpected fields passed validation. | Shared tool entry now validates the argument container, permitted keys, scalar types, size and request identifier. The voice adapter forwards the original argument value to validation. | baseline/regressions.txt, test_malformed_arguments_are_recoverable |
| QA05 / P0 | Book, cancel, reopen the database and replay the original successful booking request. The database returned a Confirmed receipt for the cancelled visit. | Persistent request caching returned obsolete JSON. Store an input fingerprint, check the owner and reconcile the original receipt with its current journal revision. Legacy unversioned requests fail closed. | baseline/lost-ack.txt, test_lost_ack_reconciles_after_restart |
| QA06 / P0 | After a slot vote, interpose an interrupted assistant turn before the tool executes. The initial fix still allowed the old vote. | A new assistant turn now revokes pending action approval. | baseline/late-vote.txt, test_unrelated_assistant_turn_invalidates_slot_vote |
| QA07 / P1 | Code inspection found a watchdog only after device initialization. An unanswered prompt had no setup deadline. | Added a preflight watchdog and abortable fetch. Detached the old audio element before asynchronous disconnect and guarded the late playback callback. | Browser test with a never-resolving media request and controlled clock |
| QA08 / P1 | An old booking result could replace a cancellation in the companion. | SQLite now supplies a per-reference event revision. React ignores older or duplicate receipts within the call. | Browser test delivers initial receipt after cancellation, waits for an ordered marker, and independently reads SQLite |
| QA09 / P1 | A late interim could reappear after finalization. A repeated committed frame could reprocess a previously supplied number. | Browser tracks finalized timestamps. The voice identity processor drops empty commits and exact duplicate frame identities in a bounded window. | Browser interim/final tests and test_identity_processor_accepts_only_committed_stt |
| QA10 / P2 | Empty roster rendered an unexplained blank schedule. SSE connection could label an initial loading schedule synced. | Added an empty result message and require a snapshot for the requested date before displaying Synced. | Browser empty-roster and HTTP recovery tests |

QA07–QA10 include code-inspection findings, with post-fix regression exercises. Pre-fix runtime evidence exists for QA01–QA06 only. Raw provider limitations are recorded separately in the verdict.
