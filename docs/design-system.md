# Reception workspace
The daily schedule is the main working surface. Use a dark forest rail, warm off-white canvas, white paper-like agenda and a narrow adjoining call desk. Give clinical dates and page titles a serif face and use system sans for controls. Align tabular time numerals consistently. Use sage for availability and a muted brick color for cancellation. All physician data is fictional. Keep the front desk, schedule and visit register reachable by keyboard. Mobile uses a compact header and stacked agenda. Call feedback uses the same doctor, time and reference as the committed register entry. Motion only marks a state change; honor reduced motion.
